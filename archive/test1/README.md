# 图论夜校 · GraphLab

十关离线图论小游戏。HTML / CSS / SVG 网页界面，Windows exe 启动，本机 HTTP 通信，不使用 WebSocket。

## 启动

双击 `GraphLab.exe`。优先使用已安装的 Edge（其次 Chrome）以独立应用窗口显示，不显示地址栏。没有这些浏览器时，会尝试默认浏览器。无需安装 Python、Node 或连接互联网。

exe 自动启动仅监听 `127.0.0.1` 的 HTTP 服务，端口自动分配。Edge/Chrome 窗口关闭后服务退出；默认浏览器后备模式会在页面停止心跳后约 3 分钟退出，也可用“菜单 → 退出游戏”立即结束。程序不请求外部资源。

本版为文件夹便携版，移动时请带上整个 `test1`。`_internal/` 是 exe 必需运行库，不能删除。游戏存档在 `data/progress.json`；专用浏览器配置及临时目录在 `data/browser/`、`data/browser-temp/`，与日常浏览器配置分开。Windows 和浏览器自身的系统日志不属于项目文件。

## 界面与操作

界面改为构成主义海报风格，参考 El Lissitzky、Rodchenko 的几何构图和印刷语言。朱红 `#D92B2B`、黑 `#111111`、旧纸米白 `#F2EDE4` 为主体，深蓝 `#1E3A5F` 仅用于禁用控件。斜置粗体、圆环与楔形构成选关海报，纸张微粒、局部半调网点和微小的红黑套印错位提供印刷质感。没有圆角、阴影、模糊、渐变、发光或 emoji。

流程为“章节海报选关 → 全屏解谜 → 通关成绩 → 章节总结”。五章横向切换，只展示当前章节的关卡入口；游戏内没有关卡侧栏。常驻文字只有一句目标、关键数值和必要按钮。提示、玩法解释、知识手记按需展开。回到选关再继续不会清空当前操作，切换其他关卡会询问是否重置。

节点直接写“邮局”“房子”“仓库”“村庄”“岛屿”“服务器”等地点名称。数值使用等宽字体，正文和按钮水平排版。正文随窗口调整为 14–20 px，游戏标题约 26–64 px。桌面推荐 1000×720 以上；窄屏地图可横向拖动。

点击地点行进/确认，点击道路修建/切断。图着色关用三角、方块、圆点、菱形、十字这五种几何标记代替额外颜色，数学规则仍是“相邻不同、种类最少”。标记与颜色等价，第三种和第四种的下限仍分别由奇环和四点完全图决定。

键盘：Tab 切换控件；地图内方向键选择目标、Enter 操作；1–5 选标记；Ctrl+Z 撤销；Ctrl+R 重来；Esc 关闭弹窗。菜单可切换音效、打开手记、退出游戏。仅保留悬停位移 2 px 和点击红色反馈，系统“减少动态效果”会停用它们。

最高星级、上次关卡和声音设置自动保存。进行中的路线不跨重启保存。旧版存档直接兼容，原动效偏好字段保留但不再引入额外动画。

## 十关

1. 第一封信：走遍街道，每条只走一次。
2. 桥那边的灯：安排过桥时机。
3. 九分钟快递：累加整条路线的时间。
4. 导航实习生：每次确认最小暂定距离。
5. 会变短的数字：观察 Dijkstra 更新旧距离。
6. 村庄通电：用最低造价连通村庄。
7. 旧桥必须留：必修道路与预算挑战。
8. 五岛灯会：奇环为什么需要第三色。
9. 中央岛的难题：四个彼此相邻的岛。
10. 最后一条备份：寻找没有绕行路线的桥。

## 源码与验证

- `app.py`：exe 入口。
- `game.py`：本机 HTTP 服务、窗口启动、规则 API。
- `engine.py`：十关数据及规则。
- `persistence.py`：便携存档。
- `web/`：海报选关界面、响应式样式、SVG 路网、文字节点和纸张微粒。
- `test_rules.py` / `test_http.py`：16 项规则测试 + 3 项 HTTP 边界测试。
- `validate_ui.py` / `verify_poster.cjs`：真实 Edge 页面点击十关、选关/继续、键盘、多尺寸截图及限定配色/禁用效果检查。
- `validate_exe.py`：从不同工作目录运行打包 exe，验证 HTTP 资源、规则操作、存档与关闭。
- `validate_window.py`：实际打开打包后的独立网页窗口，验证显示、浏览器配置位置以及关窗后服务退出。
- `verification/`：当前版本截图与测试结果。

```powershell
python -B -m unittest -v test_rules test_http
python -B validate_ui.py
python -B validate_exe.py
python -B validate_window.py
```

浏览器验证脚本使用 Playwright；可以通过 `PLAYWRIGHT_MODULE` 环境变量指定已安装模块的路径。普通游戏运行不依赖 Playwright。

重新构建需要开发机已有 Python、Pillow、PyInstaller：

```powershell
python -B build_release.py
```

构建和测试的临时文件均创建于项目文件夹内并在成功后清理。构建会替换 `_internal/`，请先关闭正在运行的游戏。
