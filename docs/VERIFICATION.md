# Tideweave 验证记录

本记录对应 2026-10-17 的关卡重设计、游戏主菜单、立体着色与旧存档迁移更新。没有重建发布包，没有改动玩家存档，没有提交或推送。

## 已通过

- `npm test`：87 项规则、边界、初学者文案、线路几何、持久化、回放和选修解锁专项测试通过；包括独立穷举 Floyd 合法路线、新版颜色上限、组合加固、旧题成绩迁移及迁移幂等性。
- `npm run verify:ui`：49 个小关都通过实际界面控件完成，检查 390、768、1440 宽度。
- `node scripts/verify-interactions.mjs`：立体面拾取、展开图同步、拖动与点击区分、WebGL 回退、故障测试恢复、章节推进通过。
- `node scripts/verify-replays.mjs`：Prim/Kruskal、增广路径、强连通缩点、Floyd 矩阵和玩家方案保护通过。
- 历史 `node scripts/verify-desktop.mjs`（10/21 随离线版一起移除）：原 0.1.0 打包 EXE 的离线启动和目录迁移通过；本轮未重新执行，也没有打包最新代码。
- `node scripts/verify-pointer.mjs`：93 条线路的真实鼠标命中、03-02.2 三种合法方案和桌面/手机截图通过。
- `node scripts/verify-local-desktop.mjs`：当前源码 Electron、规则弹窗和隔离关窗存档通过。
- `node scripts/verify-design.mjs`：章节地图不弹目标、离线字体、程序城市像素和 45 组桌面/移动关卡布局通过；没有横向溢出或说明文字裁切。
- `node scripts/verify-chapters.mjs`：五个章末、四次进入下一章前的目标确认、本章选修解锁、取消转场、旧版已读标记兼容、非章末重玩及选修结束后回到本章地图通过。
- `node scripts/verify-overhaul.mjs`：四组主菜单尺寸不重叠，锁定任务预览与出发限制，两种新立体在桌面和移动端的非空像素、拖动旋转、面拾取及展开同步，循环任务子集，中转状态说明，旧版成绩的新版参考回放均通过。已人工查看主菜单、章节路线、十四面展开图、中转对照表截图。

## 界面精修验证

本轮参考本地 PPT、用户主界面截图及 `houxin0010/distinctive-ai-design` 的设计方法，进行实际截图自查与减法调整。没有安装新运行依赖，没有分发参考作品图片或增加所需替换素材数量。

- `node scripts/verify-interface.mjs`：22 组布局，覆盖 320 至 1920 像素；主菜单、锁定关卡、章节选择、规则弹窗和设置窗口；键盘导航焦点、关卡连续编辑不重复入场、游戏内和系统减少动态效果均通过。
- 无外部网络请求；测试使用浏览器隔离存档与 Electron 临时测试目录，不修改玩家 `data/`。
- 主菜单、关卡工具、章节页和设置窗使用方角、小圆角、切角与圆形工具键的分工；关卡界面改为雾白标题与目标区、浅灰绿棋盘、炭黑操作栏和暖橙运行按钮，撤去黄色上下边框。主菜单标题下增加“图论学习游戏”副标题，并纳入多尺寸可见性与文字裁切检查。审美检查是截图自查，不是独立评审或新玩家实测。
