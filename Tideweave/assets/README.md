# Tideweave 素材入口

最终素材已按语义接入本地游戏。构建时 `scripts/build.mjs` 会把 `assets/` 原样复制到 `dist/assets/`，缺失素材仍会回退到程序图形。

| 目录 | 用途 |
|---|---|
| `scenes/` | 主菜单水网工程远景与五章关卡背景 |
| `textures/` | 棋盘工纸纹理、水脉线、田区与灯面灰度材质 |
| `nodes/` | 泵站、仓储、渠道、服务站、城区等设施，以及状态标记和分组底座 |
| `roads/` | 无向道路纹理和有向关系箭头 |
| `actors/` | 回放中的巡运标记 |

素材来自项目提供的原创文件，不修改关卡、判定或存档结构。图片均作为被动 SVG 图层显示；节点和道路的透明 SVG 热区仍负责点击与键盘操作。

章节背景在棋盘后方，按 `chapterSceneKeys` 选择，使用浅色显示以保留线路和文字对比。分组时设施本体保持原样，透明底座按分组染色，并附编号；城区与田区、街道与仓库分别匹配。工序和岗位继续使用程序图形。

田区和展开图在真实多边形内叠加灰度材质，立体灯面在本地 Canvas 中合成同款灯面材质，再由 Three.js 显示。着色仍沿用原有颜色、编号与判定，不改变区域边界或邻接关系；缺少图片时回退程序图形。无需新增模型文件。
