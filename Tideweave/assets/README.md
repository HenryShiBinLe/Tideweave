# Tideweave 素材入口

最终素材已按语义接入本地游戏。构建时 `scripts/build.mjs` 会把 `assets/` 原样复制到 `dist/assets/`，缺失素材仍会回退到程序图形。

| 目录 | 用途 |
|---|---|
| `scenes/` | 主菜单水网工程远景与五章关卡背景 |
| `textures/` | 棋盘工纸纹理、水脉线、田区与灯面灰度材质 |
| `nodes/` | 泵站、仓储、渠道、服务站、城区等设施，以及状态标记和分组底座 |
| `roads/` | 无向道路纹理和有向关系箭头 |
| `actors/` | 回放中的巡运标记 |
| `audio/` | 原创背景音乐、点击、普通通关与徽记音效 |

素材来自项目提供的原创文件，不修改关卡、判定或存档结构。图片均作为被动 SVG 图层显示；节点和道路的透明 SVG 热区仍负责点击与键盘操作。

章节背景在棋盘后方，按 `chapterSceneKeys` 选择，使用浅色显示以保留线路和文字对比。分组时设施本体保持原样，透明底座按分组染色，并附编号；城区与田区、街道与仓库分别匹配。工序和岗位继续使用程序图形。

田区和展开图在真实多边形内叠加灰度材质，立体灯面在本地 Canvas 中合成同款灯面材质，再由 Three.js 显示。着色仍沿用原有颜色、编号与判定，不改变区域边界或邻接关系；缺少图片时回退程序图形。无需新增模型文件。

## 音频

用户提供的 MP3 原样保留。运行时改用校准后的 BGM 和三种 WAV 音效；全程离线，不依赖桌面文件路径。`scripts/prepare-audio.mjs` 可用 FFmpeg 从原件重新生成播放版，玩家电脑不需要 FFmpeg。

| 播放文件 | 用途 | 实测响度 / 真峰值 | 处理 |
|---|---|---|---|
| `audio/bgm_grid_logic_mix.mp3` | 循环背景音乐 | -19.99 LUFS-I / -5.98 dBTP | 缩小长段动态差至 5.5 LU；收尾 1.6 秒交叉淡化 |
| `audio/sfx_click.wav` | 重要确认按钮和有效图上操作 | -22.1 LUFS-M / -6.1 dBTP | 裁去前 175 ms 弱起音；总长 120 ms；主声道居中；1 ms 起音、指数衰减 |
| `audio/sfx_clear.wav` | “联运有序”徽记通关 | -19.51 LUFS-I / -3.00 dBTP | 2026-10-21 再次替换为新版 2 秒完美通关音效；响度校准并控制瞬态峰值 |
| `audio/sfx_medal.wav` | 普通通关、教学关通过 | -15.99 LUFS-I / -4.93 dBTP | 响度校准，保留清脆的瞬态和尾音 |

按用户要求，普通与完美通关已交换播放素材；文件保留原名，实际用途以上表及 `src/audio.mjs` 的映射为准，制作脚本仍按原文件生成对应 WAV。

测量使用 FFmpeg `loudnorm` 与 `ebur128`，以实际解码的播放文件为准。120 ms 点击声在补零的 400 ms 窗口内测量瞬时响度，不冒充长音频综合 LUFS。峰值按上限控制，不为追求某个峰值数字额外夸大徽记音的瞬态。

上表为播放素材本身的电平，不是最终输出。运行时在统一 Web Audio 总线上增加 14 dB（上一版为 6 dB），压缩器及过采样软限幅控制高峰值，并补偿浏览器压缩器的自动增益。满档提供更高的响度余量，主音量、音效音量和音乐音量滑块步进均为 1%，可分别细调。新存档默认主音量 80%、音效音量 50%、音乐音量 50%；旧存档的滑块与开关保持原样，缺失或无效的音量按对应默认值补全。主音量统一控制两类声音；音效调至零不影响音乐。下文满档测量以三项滑块均为 100% 为准。

只播放一个音效，奖音期间不叠加点击。普通通关与“联运有序”徽记音效播放时，均将 BGM 暂时降至当前音量的 65%（约 -3.7 dB），结束后平滑恢复；短点击不触发降音。音乐尾部交叉淡化时，两路音量之和保持稳定。

先前未对徽记音效降低 BGM 时，Chromium 离线渲染整首音乐与固定操作序列，满档混音实测 -8.90 LUFS、-1.55 dBTP；同序列 6 dB 总线输出为 -14.14 LUFS，提高 5.24 LU。该数值保留为历史调音记录，不代表当前降音策略或默认音量。满档时压缩会收紧动态，实际响度提升不等于增益参数增加的 8 dB，也不能等同于所有操作序列或电脑扬声器的固定音量。运行 `FFMPEG_PATH=<ffmpeg 路径> node scripts/verify-audio.mjs` 可同时检查桌面播放与当前策略的满档离线混音；没有 FFmpeg 时仍验证信号、操作和样本峰值。

点击白名单：出发、运行检查、确认重置、继续推进以及图上有效操作。设置、页签、关卡浏览、关闭、颜色预选、撤销重做和回放控制保持安静。禁用按钮与无效图上操作不发声。原 MP3 只作为制作源保留，不参与运行时混音。详细数据见 `audio/mix-report.json`。
